Este proyecto consiste en el desarrollo de una pagina web para Vero Impresiones.
Un emprendimiento dedicado a la impresión y personalización de productos.

La página tendra como objetivo presentar los productos y servicios disponibles de manera clara, ordenada y sencilla para los usuarios. El proyecto busca mejorar la experiencia de los clientes al momento de conocer los productos, explorarlos y hacer pedidos. 

### Formulario de contacto

Para el formulario de contacto se utilizó Formspree, un servicio que permite recibir los datos enviados desde un formulario HTML sin necesidad de crear un backend propio.

El formulario incluye los campos de nombre, correo electrónico y mensaje. Se configuró el atributo action del formulario con la URL proporcionada por Formspree y el método POST, de manera que los datos ingresados por el usuario sean enviados al servicio.

Formspree es útil en este proyecto porque permite que el formulario sea funcional y pueda recibir los mensajes de los usuarios de una manera sencilla, sin tener que desarrollar un servidor o una base de datos para gestionar los envíos.
